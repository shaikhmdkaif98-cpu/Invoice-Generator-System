
# Invoice Generator System

A Python-based Invoice Generator application built using Streamlit.

## Features
- User Login and Signup
- Automatic Invoice Number Generation
- Customer Details
- Product Details
- GST Calculation
- PDF Invoice Generation
- Download Invoice
- Invoice History

## Technologies Used
- Python
- Streamlit
- Pandas
- ReportLab

## Installation

1. Clone the repository:
   git clone YOUR_GITHUB_REPOSITORY_URL

2. Install required libraries:
   pip install -r requirements.txt

3. Run the application:
   streamlit run app.py

## Project Purpose

This project was created to practice Python programming and build a simple invoice management application.
